# designer-language — Ledger

## Name

**Ledger**

## Provenance

Ledger keeps its measured rigor (tokens, dual-encoding ban, conclusion titles) while stealing upsides — not clones — from two references:

- **shadcn area charts:** quiet chrome (horizontal grid only; no axis box or tick lines) and soft series (area fill at low opacity under a thin stroke).
- **lieflat (Lupi README):** editorial density, fine hairlines, conclusion-first titles, and honest units stated once with the title.

The host is Markdown. The canvas stays transparent so the article background shows through.

## Ten locks

1. **World:** in-article editorial figure that inherits the Markdown host surface — not a dashboard card, not a poster, not an instrument panel, not a paper plate.
2. **Canvas:** transparent by default. Never paint a full-frame fill rect (no paper `#F7F4EF`, no card slab). Marks and chrome float on the host.
3. **Reading speed:** three-second judgment first (which mark wins); thirty-second verification second (exact number).
4. **Ink / Quiet / structure:** Ink `#171717`. Quiet `#737373`. Structure is ink at opacity — hairline `0.10` (grid only), axis/structure `0.28` (baseline, leaders, slice separators). One accent for one series; extra hues only for extra series.
5. **Soft mid-chroma accents:** series colors are readable mid-chroma blues/oranges/greens — never neon, never rainbow defaults. Area fill opacity `0.22` under the series stroke. Accent occupies the mark, never a filled legend slab, never the canvas.
6. **Three line grades:** hairline (ink@0.10, grid) / structure (ink@0.28, baseline + leaders) / data (1.75–2px stroke or solid fill). **No axis box.** Baseline only on the plot floor. No vertical grids. No tick lines sticking off the axis.
7. **Three type grades:** title 17 / 600 ink · unit 12 / 400 quiet · value 11 / 500 ink · tick 10 / 400 quiet. No fourth grade. No axis-name layer when the title already names the measure.
8. **Corner rule:** square frame and axes. Radius only on the data mark — bar tops `rx = 3`. No card radius.
9. **Plot share & titles:** data region owns ≥55% of frame height; grow height to 640 before crushing the plot. Horizontal grid ≤3 lines (never the baseline). Titles state a conclusion the reader can take home — never the chart type, never a bare noun that only repeats the y-field.
10. **Ornament budget zero.** Ban: paper / full-frame canvas fill, `theme:` / dark mode / second worlds, vertical grids, axis boxes, tick lines, gradients, shadows, glow, rainbow defaults, chart-type titles, dual encoding (full y-grid + every value label on n≤6), color legends when end-labels fit, fat bars that exist to fill the canvas, HTML posters, animation, d3, spline interpolation.

## Self-intro

I make editorial figures that sit in Markdown. The canvas is transparent — the article shows through. Ink is near-black; quiet gray carries units and ticks. Grid lines are ink so light they almost are not there. Axes stay quieter than marks: baseline only, no box. Soft mid-chroma accents fill areas at a whisper and stroke the edge. Numbers are body text with thousands separators. Titles state a conclusion, not a chart type. Margins grow from the widest label, but the plot keeps most of the frame. I delete every stroke that does not map to a value or a reading order.

## Closed

Transparent canvas is locked. No hedges. If a later pass needs a second world, it is a different language with a different name — not a `theme:` field on Ledger.
