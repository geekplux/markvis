# designer-language — Ledger

## Name

**Ledger**

## Ten locks

1. World: in-article editorial figure on paper — not a dashboard card, not a poster, not an instrument panel.
2. Reading speed: three-second judgment first (which mark wins); thirty-second verification second (exact number).
3. Paper `#F7F4EF`. Ink `#1C1917`. Quiet `#78716C` / `#57534E`. One accent for one series; extra hues only for extra series.
4. Accent occupies little area: the mark, never the paper, never a filled legend slab.
5. Line grades: hairline `#E7E5E4` 1px (grid only) / structure `#A8A29E` 1px (axes, leaders) / data 1.75–2px or solid fill (marks). Three grades. No fourth.
6. Type grades: title 16–18 / 600 ink · number or value 10–11 / 500 ink · note (unit) 11–12 / 400 quiet. Three grades.
7. Corner rule: square frame and axes. Radius only on the data mark, and only ≤2px on bar tops. No card radius.
8. Whitespace is structure: the data region owns ≥55% of the frame height. Labels take the rest. Never crush the plot to glorify rotated text.
9. Title states a conclusion the reader can take home. Never the chart type. Never a bare noun that only repeats the y-field.
10. Ornament budget zero. Ban: gradients, shadows, glow, rainbow defaults, chart-type titles, dual encoding (full y-grid + every value label on n≤6), color legends when end-labels fit, second themes, fat bars that exist to fill the canvas.

## Self-intro

I make editorial figures on paper. Paper is warm off-white. Ink is near-black. The grid is a ledger line so light it almost is not there. Axes stay quieter than marks. One accent hue for a single series. Numbers are body text with thousands separators. Titles state a conclusion, not a chart type. Margins grow from the widest label, but the plot keeps most of the frame. I delete every stroke that does not map to a value or a reading order.

## Closed

No hedges. If a later pass needs a second world, it is a different language with a different name — not a `theme:` field on Ledger.
