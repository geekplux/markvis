# Design specs (product surfaces)

Product-surface layout and chrome specs for Home, Play, and Examples. Charts stay **folio (Ledger)** by default — do not restyle chart marks for marketing.

| Spec | Surface |
|------|---------|
| [HOME.md](./HOME.md) | Home / landing |
| [PLAY.md](./PLAY.md) | Playground |
| [EXAMPLES.md](./EXAMPLES.md) | Examples gallery |

## Docs routes (not these specs)

**Spec / Integrate / AI / Themes** docs routes use **VitePress default** chrome (white, restore sidebar). Delete `site.css` folio paper overrides (`--folio-paper` / `#F7F4EF` full-page wash) for those routes.

GeekPlux rejects full-site beige paper as site chrome. Home / Play / Examples are product surfaces — white/near-white — not a VitePress starter and not a magazine paper wash.
