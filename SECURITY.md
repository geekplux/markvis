# Security

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x (this tree, `2.0.0`) | Yes |
| 0.0.13 (`legacy/`) | No — frozen |

## Report a vulnerability

Report privately via GitHub Security Advisories on
[geekplux/markvis](https://github.com/geekplux/markvis), or email geekplux@gmail.com.

Do not open a public issue for a security report.

This project does not run a hosted backend. The library parses Markdown and emits SVG. Include `markvis -v` or a commit SHA, a full fence, and what you expected.
