# Themes

Optional fence field `theme: folio|highcharts|shadcn|docs`. Omitted is folio. Unknown theme is an error plus table fallback.

Token packs live in `packages/themes`. Site figures stay folio unless a theme control is on. Do not restyle chart marks here.

See `docs/themes.md` in the repo for locked tokens.
