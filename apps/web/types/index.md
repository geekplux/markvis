# Chart types

Seventeen types, and no others. Each page shows when to use the type, what `x`, `y`, and `series` mean, one block with its chart, and what a wrong block shows.

| Type | Use for |
| --- | --- |
| [bar](/types/bar) | Comparing categories, in the order written |
| [line](/types/line) | A value over ordered steps or time |
| [area](/types/area) | A line with the volume under it |
| [scatter](/types/scatter) | Two numbers per row |
| [pie](/types/pie) | Parts of a whole, as given |
| [hist](/types/hist) | How raw numbers spread |
| [heatmap](/types/heatmap) | A value per pair of categories |
| [funnel](/types/funnel) | Drop-off across ordered stages |
| [waterfall](/types/waterfall) | Signed steps from a start to an end |
| [radar](/types/radar) | Several measures on one scale |
| [gauge](/types/gauge) | One value against a range |
| [sankey](/types/sankey) | Flows between nodes |
| [treemap](/types/treemap) | Sizes in a flat or two-level hierarchy |
| [dumbbell](/types/dumbbell) | Two values per category and the change |
| [bullet](/types/bullet) | Actuals against targets |
| [boxplot](/types/boxplot) | Distributions from raw rows |
| [calendar](/types/calendar) | A value per day |
