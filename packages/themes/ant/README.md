# ant theme

Static SVG grammar inspired by Ant Design Charts demos — without `@antv/g2`.

## Steal
- Muted teal / brick categorical (`#5AD8A6`, `#E8684A`, …)
- Technical axes + axis titles from IR `x` / `y` / `unit`
- Tight margins, denser interior grid (`MAX_INTERIOR_GRID: 4`)
- Annotation-friendly title (`18px`, larger `TITLE_TO_PLOT`)
- Soft plot border `#d9d9d9`
- Color legend when series ≥ 2

## Don't steal
- `@antv/g2` / AntV runtime or license
- Opaque plot wallpaper (U6: transparent fill; stroke-only border)
- Folio blue-first or highcharts demo blues
- Chart types Markvis does not have

Fence id: `ant`.
