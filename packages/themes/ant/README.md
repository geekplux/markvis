# ant theme

Static SVG grammar inspired by Ant Design Charts demos — without `@antv/g2`.

## Steal
- Muted teal / brick categorical (`#5AD8A6`, `#E8684A`, …)
- Dashed grid (`GRID.dash: "4 4"`), 4px ticks, axis titles from IR `x` / `y` / `unit`
- Haloed line points (`MARKER: "halo"`)
- Donut pie (`PIE_INNER_RATIO: 0.6`) with spider leaders
- Circle legend keys under the title

## Don't steal
- `@antv/g2` / AntV runtime or license
- Opaque plot wallpaper (U6: transparent fill)
- Folio blue-first or highcharts demo blues
- Chart types Markvis does not have

Fence id: `ant`.
